# Decentralized Learning

Aimed at building a comprehensive and user-friendly framework for decentralized learning. Start here: [**dEngine**](https://github.com/DecentralizedLearning/dEngine) 🚀

## 📦 Repositories

- [**dEngine**](https://github.com/DecentralizedLearning/dEngine) — A decentralized learning framework. This is the core project and the best entry point.
- [**notebooks**](https://github.com/DecentralizedLearning/notebooks) — Notebooks needed for experiments and visualization.
- [**dengine-uciml**](https://github.com/DecentralizedLearning/dengine-uciml) — Extends dEngine with support for UCI ML datasets.

## 🤝 Contributing

Contributions, issues, and feature requests are welcome. Check out the individual repos above to get started.
